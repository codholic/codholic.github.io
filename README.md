# codholic.github.io

Personal academic website of Mohammad Redwan Islam, live at https://codholic.github.io

- `index.html`: all content (About, Research, Experience, Projects, Achievements, Contact)
- `assets/css/style.css`: styling (Notre Dame blue/gold, light + dark mode)
- `assets/img/`: photo, figures, favicon

To update: edit `index.html`, then `git add -A && git commit -m "update" && git push`.
The site rebuilds automatically in about a minute.
